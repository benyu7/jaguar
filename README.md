# Jaguar

A Tauri desktop app in vanilla HTML, CSS and TypeScript.
- Pico CSS

## Prerequisites
- gh cli

## Run
- install the [GitHub CLI](https://cli.github.com) and run `gh auth login`
- pnpm install
- pnpm tauri dev
- pnpm tauri build
- ./src-tauri/target/release/jaguar

## Details
- Windows, MacOS, Linux
- Authentication is the GitHub CLI's gh
